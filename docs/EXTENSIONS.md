# 本轮实现与边界

## 一条动作链

`humanoid/runtime.py` 继承上游环境，只扩展 step 前的动作处理与外力注入。机器人模型、PD执行器、物理步进、接触与重置仍由固定版本GenesisLab管理，不复制其核心循环。

`ActionPipeline` 依次处理：可选的踝关节反馈位置目标、RL残差比例、动作限幅、可选的PD目标区间投影。训练与评价经过同一实现，观测中的last_action记录实际交给上游环境的动作。

原始actor导出不包含这条有状态物理输入的处理链。导出元数据显式记录controller/shield与postprocessing_required，不能把raw actor直接当成完整残差控制器部署。

## 已实现的随机化

摩擦比、躯干附加质量、刚度比例、阻尼比例均通过Genesis原生接口实现；显式开启batch_links_info/batch_dofs_info。startup时采样一次，每个episode不重复叠加随机化。

`get_links_inertial_mass()`只读名义惯性质量，质量偏移另在native solver中保存。`humanoid/native.py`将两者相加，以有效质量计算全身CoM和实际质量清单。烟测验证不同环境具有不同质量和增益，不把配置文件存在当作随机化已经生效。

`pd_gains`是固定控制器标定，与随机化分开记录。刚度乘s、阻尼乘sqrt(s)保持原设定阻尼比；effort_limit和机器人质量不变。高刚度的仿真站立成功不代表真实电机带宽、热约束或实机安全已经验证。

## 动作过滤与soft penalty

soft penalty惩罚关节位置超出软范围。PD目标过滤将目标位置范围、归一化动作范围和名义仿射PD力矩范围取交集；交集为空时优先满足动作/位置目标范围，并记录infeasible。它不保证下一时刻关节位置或实际隐式求解力矩满足同一约束，不保证接触稳定或避免跌倒。

## 外力与恢复

力的单位N，施加点是躯干link COM，方向为世界系，每个控制步重新注入。起始时刻和持续时间必须是控制周期的整数倍，避免浮点边界多施加一步。记录实际请求冲量，不用直接改速度冒充力。

push_exposure_rate表示实际活到外力时刻的episode比例。只在确实受到力的episode中计算recovery_rate；无人受到力时返回null。恢复要求外力结束后倾角≤0.35rad、线速度误差≤0.2m/s持续0.5s，随后未发生物理终止。此恢复阈值是实验定义，非稳定域证明。

## 配对评价和运行状态

version-2协议将物理条件与方法配置分开。奖励、策略网络、残差和shield可以不同，但机器人、PD标定、地形、重置范围、测试参数分布、指令计划、时限、阈值、seed与并行环境数必须一致。命令由独立NumPy生成器提前生成，保存完整计划与SHA256。

五seed汇总在训练seed层面计算mean/std/median，拒绝把同一seed的多次评价合并成独立训练样本。所有工程验证seed均已暴露；不能称为正式盲测。

统一ghrl入口延迟导入物理依赖，帮助和任务发现不构建场景。状态与结果JSON采用原子替换；失败保留明确状态。sweep顺序运行以限制内存，某job失败即停止，保留此前产物。源码快照保存每次运行时未提交的实际代码。
