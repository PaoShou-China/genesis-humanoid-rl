# 本轮工程与实测结果

2026-11-26，开发版 `0.1.0.dev1`。核心变化：先校准关节PD，再统一扩展任务、控制与评估。**已获得可重复的站立和一个推扰工况的参考控制；PPO行走尚未收敛，完整V0.1仍不标记完成。**

## 当前实测

| 配置/实验 | 真实运行量 | 结果 |
|---|---|---|
| 名义姿态PD增益扫描 | 同一初始姿态，刚度倍率1/2/4/8/16/32，阻尼配套乘sqrt(s) | 8、16、32倍组完成20s站立；低增益组跌倒 |
| H1，刚度×8、阻尼×sqrt(8) | 8个完整episode，关节初始扰动±0.1rad | 6/8成功；平均存活15.605s |
| **H1，刚度×16、阻尼×4** | **8个完整episode，每次20s，初始扰动±0.1rad** | **8/8成功，跌倒0；平均每episode最大倾角0.0674rad** |
| **H3，相同PD，躯干+x方向30N×0.1s** | **8个完整episode，每次20s，第5s推扰，冲量3N·s** | **8/8实际受到力并恢复，跌倒0** |
| H1 PPO，survival奖励与较小探索 | 32环境×24步×1000轮=768,000 transitions | 8次评价成功0；平均存活1.4325s |
| H1 PPO，8倍PD与较小探索 | 32环境×24步×300轮=230,400 transitions | 与同PD参考配对评价，成功0；平均存活1.805s |
| PPO+DR五seed闭环 | seeds0–4，各2轮训练+独立2个episode | 10个job全部完成，模型/评价/聚合正常；成功率均0，不是收敛实验 |
| 分布偏移评价 | 实际改变质量、摩擦、PD比例并执行已保存策略 | 接口通过，策略成功率0；不宣称OOD鲁棒性 |
| H4粗糙地形 | 真实物理步进+2轮PPO更新 | actor123维、critic133维；训练/保存通过，非地形成功率验收 |

所有PD倍率均只改变控制器刚度与阻尼，**不提高电机力矩上限，不降低重力，不固定机器人根节点**。H1/H3的控制力矩接口越界比例为0。高增益的仿真结果不等于真实电机带宽、热约束或实机安全验证。

增益扫描是单组固定姿态下的对照，支持“底层PD配置会显著影响本模型的站立结果”；不能把所有RL失败都归因于PD。两组PPO开发配置仍失败，学习策略、探索、奖励和训练预算需要继续独立诊断。这里的201–204、301–304等评价种子已经用于工程验证，不称为正式盲测。

## 已补齐的可执行功能

| 模块 | 实现与检查 |
|---|---|
| 统一入口 | `ghrl` / `python -m humanoid`，子命令帮助与任务发现，无场景初始化 |
| 控制 | 一条ActionPipeline供训练/评估共用；固定PD标定、反馈位置目标、RL残差、动作限幅 |
| Safe RL对照 | soft joint-limit penalty与PD目标shield分开；不可行交集明确标记，不宣称形式化保证 |
| DR | 摩擦、躯干附加质量、PD比例；验证各环境实际参数不同；CoM使用包含质量偏移的有效质量 |
| H3 | native solver真实link COM外力；整数控制步脉冲，力改变实际轨迹的测试通过 |
| H4 | 复用上游真实rough terrain与传感器，不复制或改写物理核心 |
| H5数据入口 | 校验真实NPZ的fps/名称/形状/有限值/四元数；拒绝pickle对象，不伪造动作数据 |
| 配对评估 | 物理协议与方法配置分开；完整命令计划+SHA256，首个完整episode与终止状态采样 |
| 科研统计 | 五seed顺序执行；按独立训练seed汇总，拒绝重复seed伪增样本；无推扰暴露时恢复率null |
| 可视化 | 真实姿态/CoM/关节/接触/机械功率/外力图；相同条件并排视频，结束帧明确标记 |
| 工程 | 原子JSON、失败状态、源码快照、并行预取固定资产与哈希、wheel与CLI、CPU CI工作流 |

本地检查：**31项测试通过，Ruff格式/静态检查通过；wheel构建并检查关键脚本和配置均已打包。** GitHub CI提供工作流，不用本地通过替代远端CI状态。
